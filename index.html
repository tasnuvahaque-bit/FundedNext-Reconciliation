Nuvei AE Settlement Reconciliation
3-step match: BridgerPay Col H → Nuvei Col Z → Network International PA Col D
🏛️ Open NI PA Report Converter ↗ Convert the Network International PDF → upload the Excel below
🔄
BridgerPay Report
Col H: processingId · Col Q: status · Col I: amount
📊
Nuvei AE Report
Col Z: processingId · Col Y: authCode · Col H: result
🏛️
Network Intl PA Report
Col D: authCode · Col F: MSF · Col G: Fee · Col H: VAT
Matching Process:
1️⃣ Verify: BridgerPay Status (Col Q) = Nuvei Transaction Result (Col H)
2️⃣ Match: BridgerPay Col H → Nuvei Col Z
3️⃣ Verify: Nuvei Col Y → PA Col D
✓ All steps verified = SETTLED  |  ✗ Any step failed = UNSETTLED
